# Security Policy

## Supported Versions

Only the latest published version of `create-nala` on npm and the `main` branch of this repository receive security fixes.

| Version | Supported |
|---|---|
| `3.x` (latest) | ✅ |
| `< 3.0` | ❌ |

---

## 🔒 Reporting a Vulnerability

**Please do NOT report security vulnerabilities through public GitHub Issues.**

If you discover a security vulnerability in Nala (including the scaffolding CLI, starter template, or showcase app), please report it responsibly via **private disclosure**:

### Option A: GitHub Private Advisory (Recommended)

Use GitHub's built-in private vulnerability reporting:

1. Go to the [Security tab](https://github.com/candrasp/Nala/security) of this repository.
2. Click **"Report a vulnerability"**.
3. Fill in the details of the vulnerability.

This creates a private thread between you and the maintainers — **not visible to the public**.

### Option B: Direct Contact

If GitHub's advisory system is unavailable, contact the maintainer directly via the email listed on the [GitHub profile](https://github.com/candrasp).

---

## 📋 What to Include in Your Report

A helpful vulnerability report includes:

- **Description** — What is the vulnerability and where does it exist?
- **Impact** — Who is affected and what can an attacker do?
- **Steps to Reproduce** — A minimal, reproducible example or PoC.
- **Affected versions** — Which version(s) of `create-nala` or the template are affected?
- **Suggested fix** (optional) — If you have an idea how to address it.

---

## ⏱️ Response Timeline

| Stage | Target |
|---|---|
| Acknowledgement | Within 48 hours |
| Initial assessment | Within 5 business days |
| Fix & release (if confirmed) | Within 14 days for critical issues |

---

## 🙏 Responsible Disclosure

We ask that you:

- Give us reasonable time to investigate and fix the issue before any public disclosure.
- Do not access, modify, or delete any data that is not yours.
- Do not perform denial-of-service attacks.

In return, we commit to:

- Acknowledging your report promptly.
- Working with you to understand and address the issue.
- Crediting you in the fix notes (if you wish).

Thank you for helping keep Nala safe! 🛡️
